How to make a page like this

This site is deliberately just one HTML file. There is no framework, build step, database, or JavaScript dependency.

1. Start with four notes

  • What I built: what it does and why.
  • Where I got stuck: the hard part.
  • What I tried and learned: what changed.
  • What I’m exploring next: the open question.

2. Ask for the artifact

Use this prompt: “Create a simple, welcoming one-page website artifact to showcase something I built. Use these notes to tell a clear, honest story. Keep my voice. Don’t invent results or experience. Use readable text, a clean layout, make it work on phones, and keep it easy to update.”

3. Keep the implementation boring

Put the content, styles, and structure in a single index.html. Use semantic HTML, responsive type with clamp(), a narrow reading width, and one small mobile breakpoint.

4. Publish it

Put index.html in a public GitHub repository and serve it with GitHub Pages. For a user site repository named USERNAME.github.io, a folder such as project-story/index.html becomes https://USERNAME.github.io/project-story/.

5. Update it

Replace the bracketed placeholders, remove the demo-link block if you do not need it, and commit the file again. The page requires no rebuild.

The constraint is intentional: the artifact should be easier to change than the project it describes.
