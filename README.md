# dhk.github.io

A curated public launchpad for DHK's writing, live web projects, and selected
open-source repositories.

## What belongs here

The page links to:

- [www.dhk.io](https://www.dhk.io), the main site;
- GitHub Pages projects that have been verified as publicly reachable; and
- public repositories with a clear problem, useful artifact, or idea worth
  carrying forward.

This is intentionally not a complete mirror of the
[dhk GitHub profile](https://github.com/dhk). Early placeholders, private work,
archives, and repositories without a useful public story are omitted.

## Updating the page

The site is a single, dependency-free [`index.html`](index.html). Edit it
directly and verify:

1. every destination returns a successful response;
2. descriptions agree with the linked repository's current README;
3. unfinished work is labelled honestly; and
4. the page remains usable at narrow and wide viewport sizes.

GitHub Pages serves the default branch at
[https://dhk.github.io](https://dhk.github.io).
